# NeuroForecaster AI Platform

A research-grade AI-powered web prototype for advanced Brain Tumor Segmentation and Future Spread Forecasting.

## Setup
1. Install dependencies: `pip install -r backend/requirements.txt`
2. Ensure `model/brain_tumor_progression_model.pth` exists.
3. Run the backend: `python backend/app.py`
4. Visit `http://localhost:5000`

## Features
- **Multimodal MRI Analysis** (FLAIR, T1, T1CE, T2)
- **Tumor Growth Forecasting**
- **Explainable AI (Grad-CAM)**
- **Medical Dashboard Aesthetics**
