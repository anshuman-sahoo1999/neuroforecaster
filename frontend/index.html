Research Technical Specification

Architecture: 3D Residual U-Net

The system utilizes a 3D U-Net architecture. It features residual connections to prevent vanishing gradients and multi-scale feature extraction for global context.

Multi-Modal Fusion

Performs Concatenative Fusion of FLAIR, T1, T1CE, and T2 sequences to differentiate between edema, enhancing tumor, and necrotic core.

Mathematical & Physics Foundations

  • Segmentation Loss (Dice Coefficient): Used to handle class imbalance:
    \[ DSC = \frac{2 |A \cap B|}{|A| + |B|} \]
  • Tumor Kinetics (Fisher-KPP): Models biological infiltration:
    \[ \frac{\partial u}{\partial t} = D \nabla^2 u + \rho u(1-u) \]
  • Explainability: Grad-CAM highlights anatomical regions influencing the AI's prognosis.
